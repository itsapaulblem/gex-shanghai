Overview

What the website does

The website is an online extension of the Shanghai People's Park marriage market. A parent or family member creates an anonymous child profile, reviews other profiles, sends approval-based connection requests, and chats privately after both sides agree.

Exchange text and image messages with a connection.

Before you begin

Use a valid email address and prepare a password with at least 8 characters, one uppercase letter, and one special character. The current version does not use OTP verification or a password-reset feature.

1

Account access

Create an account

Open the website. The registration screen is selected automatically.

  1. Choose the interface language.
    Select the globe button in the top-right corner to use Chinese or English.
  2. Select “Create account”.
    Use the tab on the account card if it is not already selected.
  3. Enter an email address.
    The email must have a valid format, such as name@example.com.
  4. Create a strong password.
    Use 8 or more characters, including at least one uppercase letter and one special character.
  5. Select “Create account”.
    A successful registration signs you in and opens profile setup automatically.

2

Required setup

Create the child profile

A completed child profile is required before Browse, Connections, and Chat become available. Required fields are marked with an asterisk.

Step 1 of 3

Basic information

  • Parent title and surname
  • Child alias and gender
  • Birth year and calculated age
  • Height and weight
  • Hukou and hometown
Step 2 of 3

Education and career

  • Highest education
  • School and major
  • Industry and job title
  • Monthly income
  • Property and car status
Step 3 of 3

Story and preferences

  • Personality and hobbies
  • Preferred age and height
  • Education and hukou preference
  • Additional preferences
  • Parent's note
  1. Complete every required field in the current step.
  2. Select Next step to continue. Use Previous step to make corrections.
  3. Enter height and weight using digits only.
  4. Separate personality traits with commas so they appear as individual tags.
  5. On Step 3, select Submit profile. You will be taken to the Browse page.
3

Discovery

Browse and filter profiles

The Browse page displays anonymous profiles in cards. Each card summarizes gender, age, height, city, hukou, education, personality, school, career, and monthly income.

Search and filters

  • Keyword search
  • Gender
  • Age range
  • Minimum height
  • Minimum education
  • Monthly income

Sorting

  • Latest profiles
  • Age: low to high
  • Age: high to low
  • Height: low to high
  • Height: high to low
  1. Enter one or more keywords, such as a city, school, industry, or hukou.
  2. Choose any filters that matter to you.
  3. Select a sorting option.
  4. Review the results and use the page controls to see more profiles.
4

Review

View a complete profile

  1. Select View detail on a profile card.
  2. Review basic information, education, career, finances, property, partner preferences, and the parent's note.
  3. Select Back to list if the profile is not suitable.
  4. If interested, select Request to connect.

Profiles use a child alias rather than contact information. Direct conversation remains unavailable until the request is approved.

6

Request management

Manage connections

Select My Connections in the header. The page has three sections:

Incoming

Requests received

View the complete profile, then approve or reject the request.

Outgoing

Requests sent

Review the profile or cancel a request that is still pending.

Connected

Approved matches

View the profile, open private chat, or remove the connection.

Removing a connection

The website asks for confirmation twice. Once removed, chat closes and a new request is required to reconnect.

7

Communication

Use private chat

  1. Open My Connections.
    Find the person under Connected and select Open chat.
  2. Review the profile summary.
    The side panel also shows online or offline status and last-seen information.
  3. Send a text message.
    Type a message and select Send, or press Enter.
  4. Attach an image if needed.
    Select the image button, choose an image smaller than 1.8 MB, review the preview, and send it.
  5. Manage a message.
    Right-click a message. Your own message can be deleted for both users; any message can be hidden from your view.

The chat refreshes automatically and shows when the other person is typing.

8

Account controls

Edit the profile or sign out

  • Select My Profile to reopen the three-step form, make changes, and select Save changes.
  • Select the site logo to return to Browse.
  • Use the globe button to switch languages.
  • Select Sign out to end the session and return to the account screen.
